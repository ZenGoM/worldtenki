# 画面仕様書：WorldTenki（天気予報アプリケーション）

## 1. 画面概要
本アプリケーションは、Open-Meteo APIを活用し、指定された都市の現在の天気、1時間ごとの予報、および14日間の長期予報を直感的かつ美しいUIで表示するシングルページWebアプリケーションです。季節や天候に応じて背景画像やグラデーションが動的に変化し、リッチなユーザー体験（UX）を提供します。

---

## 2. 全体レイアウト・共通仕様
* **ターゲットデバイス**: モバイルファースト設計（最大幅 `400px` のコンテナ内に最適化配置）
* **フォント**: `Outfit`, sans-serif
* **アイコンシステム**: [Lucide Icons](https://lucide.dev/)
* **グラフ描画**: [Chart.js](https://www.chartjs.org/)
* **テーマ・背景**:
  * 現在の月（季節）に応じて背景画像を自動切り替え（春・夏・秋・冬）
  * 現在の天候状態に応じて背景グラデーションカラーを自動適用（快晴、雨、雪など）
  * グラスモーフィズム（半透明のぼかし効果）を取り入れたカードデザイン

### 3.2 現地時間カード
ヘッダーエリアとメインの天気カードの間に配置される、現在時刻を表示するカードです。

| 要素名 | UI部品 / タグ | 仕様・動作 |
| :--- | :--- | :--- |
| **現地時間** | `<div>` | • 選択された都市の現在時刻を24時間制（HH:MM:SS）でデジタル時計風のフォント（`Share Tech Mono`）で表示。<br>• 1秒ごとに更新。 |

### 3.3 現在の天気カード（メインエリア）
画面中央に大きく配置されるメインカードです。

| 要素名 | UI部品 / タグ | 仕様・動作 |
| :--- | :--- | :--- |
| **天気アイコン** | `<i>` (Lucide) | • 天候コードに応じたアイコンを表示。<br>• 常時上下にゆっくりと揺れるフロートアニメーション（`float`）を適用。 |
| **現在の気温** | `<h2>` + `<span>` | • 取得した現在の気温を整数に四捨五入して表示（単位：`°C`）。 |
| **天候テキスト** | `<p>` | • APIのWMO気象コードに基づき、日本語の天候状態（「快晴」「曇り」「雷雨」など）を表示。 |
| **詳細情報（降水確率）** | 複合要素 | • 当日の最高降水確率を表示。 |
| **詳細情報（湿度）** | 複合要素 | • 現在の相対湿度（`%`）を表示。 |
| **詳細情報（風速）** | 複合要素 | • 現在の風速（`m/s`）を表示。 |

### 3.4 1時間ごとの予報エリア
横スクロール可能なコンテナ内に、直近12時間の予報と気温推移グラフを統合して表示します。

| 要素名 | UI部品 / タグ | 仕様・動作 |
| :--- | :--- | :--- |
| **時間・アイコン・降水確率列** | Flexbox列 | • 現在時刻を起点とした今後12時間分のデータを等間隔で配置。<br>• 先頭列は「現在」、以降は「HH:00」形式で表示。<br>• 各時間帯の天候アイコンと降水確率を表示。 |
| **気温推移折れ線グラフ** | `<canvas>` (Chart.js) | • スムーズな折れ線グラフ（`tension: 0.4`）で気温の変化を視覚化。<br>• グラフ下部は白の半透明グラデーションで塗りつぶし。<br>• **カスタムプラグイン**により、各データポイントの上部に直接気温テキスト（「〇°」）を描画。 |

### 3.5 14日間の天気予報エリア（長期予報）
リスト形式で日ごとの予報を一覧表示します。

| 要素名 | UI部品 / タグ | 仕様・動作 |
| :--- | :--- | :--- |
| **日付・曜日** | `<span>` | • 本日は「今日」、翌日は「明日」、それ以降は「〇曜日」として表示。<br>• サブテキストとして「M/D」形式の日付を表示。 |
| **降水確率** | `<div>` | • 日ごとの最大降水確率を青色テキストで表示。 |
| **天候アイコン** | `<i>` (Lucide) | • 日ごとの代表天候アイコンを表示。 |
| **最高・最低気温** | `<span>` | • 最高気温（赤系色）と最低気温（青系色）を並べて表示。 |

## 4. 地球儀モーダルエリア
「地球儀から選ぶ」ボタンで開く、画面全体を覆う3Dインタフェースです。

| 要素名 | UI部品 / タグ | 仕様・動作 |
| :--- | :--- | :--- |
| **3D地球儀** | `<canvas>` (Globe.gl) | • 登録された全都市をラベルとしてマッピング表示。<br>• ドラッグで回転、ホイール・ピンチでズームが可能。<br>• 都市名をクリックすると、対象都市が選択され、データ更新後にモーダルが自動で閉じる。 |
| **閉じるボタン** | `<button>` | • 右上に配置されたボタンでモーダルを閉じる。 |

---

## 5. エラー・ローディング処理
* **データ取得中**: 天候テキストエリアに「取得中...」と表示し、更新ボタンのアイコンを回転させます。
* **データ取得失敗**: 天候テキストエリアに「取得エラー」と表示し、コンソールに詳細なエラーログを出力します。

## 6. 外部API (Open-Meteo API) アクセス仕様
本アプリケーションは、天気予報データを取得するために [Open-Meteo API](https://open-meteo.com/) を利用します。

* **エンドポイント**: `https://api.open-meteo.com/v1/forecast`
* **メソッド**: `GET`
* **必須パラメータ**:
  * `latitude`: 対象都市の緯度
  * `longitude`: 対象都市の経度
* **取得データパラメータ**:
  * `current`: `temperature_2m` (現在の気温), `relative_humidity_2m` (現在の湿度), `weather_code` (現在の天候コード), `wind_speed_10m` (現在の風速)
  * `hourly`: `temperature_2m` (1時間ごとの気温), `weather_code` (1時間ごとの天候コード), `precipitation_probability` (1時間ごとの降水確率)
  * `daily`: `weather_code` (日ごとの代表天候), `temperature_2m_max` (最高気温), `temperature_2m_min` (最低気温), `precipitation_probability_max` (日ごとの最大降水確率)
* **その他のパラメータ**:
  * `forecast_days=14`: 14日分の予報を取得
  * `timezone=Asia/Tokyo`: 日本標準時に合わせた時間軸でデータを取得（都市によらず基準として使用）
* **アクセス仕様の特徴**: 
  * Open-Meteo APIは都市名ではなく、緯度・経度を指定して気象データを取得します。そのため、アプリケーション内で各都市名と緯度・経度座標をマッピングし、APIリクエスト時に適用しています。
